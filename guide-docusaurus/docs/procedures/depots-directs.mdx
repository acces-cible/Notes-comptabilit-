# 2.0 Dépôts directs

<Alerte type="info">Vérifier les courriels dans Thunderbird depuis la date du dernier dépôt. Chercher : « Avis de dépôt - Paiement de factures »</Alerte>

## Étapes

1. Retrouver la facture dans « factures à recevoir »
2. Imprimer la confirmation du paiement et mettre avec la facture
3. Écrire les infos comme un chèque normal, mais ajouter sur la page de gauche :
   - **No. de paiement**
   - **Date du paiement**
